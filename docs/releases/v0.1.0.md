# LASSO Pipeline Desktop 0.1.0

Première version publiable de l'application locale LASSO Pipeline Desktop.

## Points forts

- application Linux autonome ;
- moteur scientifique Python embarqué ;
- aucune installation Python requise ;
- traitement local des données ;
- jobs persistants et récupérables ;
- import natif des fichiers HRMS ;
- suivi des traitements longs ;
- ouverture et export des résultats.

## Paquets Linux

- lasso-pipeline-desktop_0.1.0_amd64.deb
- lasso-pipeline-desktop-0.1.0-1.x86_64.rpm
- lasso-pipeline-desktop_0.1.0_amd64.AppImage

## Configuration minimale recommandée

- Linux x86_64 ;
- environnement graphique compatible GTK et WebKitGTK ;
- 4 Go de mémoire vive au minimum ;
- 8 Go de mémoire vive recommandés pour les traitements scientifiques ;
- au moins 2 Go d'espace disque libre pour l'application, l'extraction temporaire du sidecar et les premiers jobs ;
- espace supplémentaire adapté au volume des données HRMS.

## Installation rapide avec l'AppImage

    chmod +x lasso-pipeline-desktop_0.1.0_amd64.AppImage
    ./lasso-pipeline-desktop_0.1.0_amd64.AppImage

## Limites connues

- publication initiale limitée à Linux x86_64 ;
- absence de signature cryptographique des paquets ;
- absence de mise à jour automatique ;
- premier démarrage plus lent en raison de l'extraction du sidecar PyInstaller ;
- avertissement Dask relatif à dask-expr encore visible dans les journaux ;
- résultats scientifiques à valider selon les protocoles du laboratoire.

## Intégrité des fichiers

Vérifiez les empreintes publiées avec :

    sha256sum -c SHA256SUMS
